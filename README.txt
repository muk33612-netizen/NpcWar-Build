NpcWar - ม็อด ScriptHookV (C++ ล้วน ไม่ใช้ .NET) สำหรับโหมดเนื้อเรื่อง

ติดตั้ง: ก๊อป NpcWar.asi + NpcWar.ini ไปไว้โฟลเดอร์เกมที่มี ScriptHookV.dll
คอมไพล์: ดู build.bat (ต้องมี ScriptHookV SDK จาก dev-c.com/gtav/scripthookv)

ระบบ
- NPC รวม 50 คน แบ่ง ขอทาน 10% / แก๊ง 70% / ตำรวจ 20% (แก้ใน ini)
- แก๊งกับตำรวจเดินเล่นมือเปล่า แล้วสุ่มวิ่งมารุมตีเรา (อาวุธสุ่ม: มีด ไม้ มีดพร้า ปืนต่างๆ)
- ถ้าเราตีใครสักคน คนรอบๆ มีโอกาสรุมด้วย
- NPC อึด ล้มไม่ได้ (ปิด ragdoll) ไม่หนี ไม่โดน headshot ตายทันที เลือด 3000
- ขอทานเป็นฝั่งเรา เดินตาม ช่วยตี/ยิงแก๊งกับตำรวจ แก๊งและตำรวจจะจัดการขอทานด้วย
- R ใกล้ศพ = ชุบ (ศพตำรวจ/แก๊ง/ขอทานก็ได้ ชุบแล้วมาอยู่ฝั่งเรา)
- Space ใกล้ศพ = อุ้มแบกบ่า กดซ้ำ = วาง (ระหว่างอุ้มกด R = ชุบ)

--- บน GTA V Port (iOS) ---
ติดตั้งเฉพาะ NpcWar.asi + NpcWar.ini (ไม่ใช่ .cpp) ผ่าน Settings > Mods > Install a mod...
ต้องคอมไพล์ .asi จากเครื่อง Windows หรือใช้ GitHub Actions (.github/workflows/build.yml)
